# 📋 Tableau de bord des profils

Le suivi de **chaque profil** du [QCM examen](index.md) : par exemple Ana passe le **CCP 1**, puis le **CCP 2**, puis **repasse** le CCP 1 ; chaque passage s'enregistre dans son profil et le tableau de bord montre son **évolution**.

!!! info "Ce que tu trouves ici"
    - **Récapitulatif** de tous les profils : dernier score de chaque CCP et son évolution, **taux de réussite**, compétences maîtrisées, dernière activité.
    - **Détail d'un profil** (bouton *Voir le détail*) :
        - la **courbe** de chaque CCP, avec le premier score, la moyenne et le meilleur score ;
        - un **commentaire** sur les **points forts** et les **points faibles** ;
        - la maîtrise des **10 compétences** ;
        - le **parcours** complet, avec l'évolution et le commentaire de chaque passage.
    - **▶️ Passer un QCM avec ce profil** : rend le profil actif et ouvre la page des épreuves.

!!! warning "Où sont enregistrés les profils ?"
    La base de profils est enregistrée **dans ce navigateur**, sur cet appareil : rien n'est envoyé sur Internet.

    - **Changer d'appareil :** *Exporter tous les profils* crée un fichier, à importer sur l'autre appareil.
    - **Navigation privée :** les profils sont effacés en fermant la fenêtre.
