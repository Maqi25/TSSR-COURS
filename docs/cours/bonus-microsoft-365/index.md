# Bonus - Microsoft 365

!!! abstract "Informations pratiques"
    **Support :** cours ENI « Outils collaboratifs : Microsoft 365 » (module d'introduction du programme)

    **Lieu :** En ligne (Campus en ligne)

Ce cours bonus couvre les outils collaboratifs que le technicien installe, configure et dépanne au quotidien : le **tenant** Microsoft 365, **Word**, **Excel**, **Outlook**, **Teams**, **SharePoint** et **OneDrive**.
